# 🦈 Wyckoff Shark - Sistema de Trading Automático

Sistema profesional de trading automático basado en la metodología Wyckoff para Binance Futures.

## Características
- Análisis multi-timeframe
- Señales LONG/SHORT automáticas
- Gestión de riesgo integrada
- Ejecución automática con Binance

## Configuración
1. Configura tus claves API de Binance
2. Ajusta parámetros de riesgo
3. Activa el modo LIVE si deseas trading real
